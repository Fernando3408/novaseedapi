# NovaSeed mascot assets

La base usa un SVG inline transparente para evitar una petición adicional y mantener el avatar nítido en cualquier tamaño.

Assets definitivos sugeridos:

- static/mascot-blob-idle.svg
- static/mascot-blob-thinking.svg
- static/mascot-blob-success.svg
- static/mascot-blob-warning.svg
- animated/mascot-blob-thinking.lottie o .webp/.apng

El componente ya expone estados, animación y fallback estático. Las animaciones de producción pueden conectarse aquí sin cambiar la lógica de los modales.
